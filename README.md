# 🍟 麦门拼单官（mcd-group-split）

> 办公室拼单点麦当劳：**自动凑出券后最优价，再把订单实付精确分账到每个人——分毫不差。**

基于 [麦当劳中国官方 MCP 服务](https://github.com/M-China/mcd-mcp-server) 开发的参赛 Skill ——
**2026 麦当劳程序员创意开发大赛**，使用 [WorkBuddy](https://www.workbuddy.cn/) 开发。

## 为什么需要它

一群人拼单点麦当劳，券能领、满减能凑，但最后总会卡在同一件事上：

> **省下来的钱，每个人该分多少？**

点得多的人觉得自己该少付，点得少的人觉得优惠应该均摊。
于是发起人默默垫了钱，或者群里为几块钱来回扯皮。

市面上的点餐助手都在解决「怎么点」，没人解决「怎么算」。
**麦门拼单官把分账做成确定性算法**——不是让 AI 估算，而是可测试、可审计的整数运算。

## 它凭什么算得对

分账最容易出的问题是**加总对不上**：三按比例分 `¥29.70`，
AI 给出 `¥8.49 / ¥9.71 / ¥11.50`，加起来正好——但每一项都和正确值差 1 分钱，是「凑出来」的。

本项目用**最大余数法**做整数分摊，并写死保证：

> **各人应付之和 ≡ 订单实付，一分钱都不差。**

`tests/test_split_bill.py` 里有一条穷举压测，遍历多组人数、金额、分摊口径，
断言每一种组合下加总都守恒。**选品和讲解交给大模型，钱交给可测试的代码。**

## 它做什么

| 模式 | 你说 | 它做 |
|---|---|---|
| 🧾 **发起拼单** | 「办公室 4 个人拼个麦当劳，到店自取」 | 定门店 → 拉菜单 → 输出可转发到群里的**精简菜单摘要** |
| 🎫 **券后最优** | 「今天有什么券能凑」 | 一键领券 → 汇总**我的券 + 本店券 + 当日活动** → 生成 3 档组合 → 逐组实算券后价，给出最便宜的那档 |
| 🧮 **公平分账** ★ | 「用券之后每个人该付多少」 | 按原价比例（或按人头均摊）把订单实付**精确拆分**，输出可直接发群的账单 |
| ✅ **确认下单** | 「就按方案 B 来，下单」 | 复核价格 → 明细确认 → 创建订单 → 出支付链接，**未经确认绝不动你的钱** |

## 快速开始

### 1. 申请麦当劳 MCP Token

前往 [`open.mcd.cn/mcp`](https://open.mcd.cn/mcp) → 手机号登录 → 右上角「控制台」→「激活」→ 复制 Token。

### 2. 配置 MCP 连接器

在支持 MCP 的客户端中添加（示例见 `mcp-config.example.json`）：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": { "Authorization": "Bearer ${MCD_MCP_TOKEN}" }
    }
  }
}
```

> ⚠️ 务必把 `${MCD_MCP_TOKEN}` 换成你自己的 Token（或让客户端从环境变量读取），**不要提交到仓库**。

### 3. 装载技能

把本仓库放入客户端的 skills 目录：

- **WorkBuddy**：`~/.workbuddy/skills/mcd-group-split/`
- **Claude Code / 其他 Agent**：放入对应的 skills 目录（`SKILL.md` 为通用格式，不绑定特定框架）

### 4. 直接用分账功能（不需要 Token）

分账是纯本地计算，可以脱离 MCP 单独跑：

```bash
python scripts/split_bill.py --total 29.70 \
  -m 小美:14.00 -m 阿强:16.00 -m 老王:19.00
```

```
🍟 麦门拼单官 · 分账账单
订单实付 ¥29.70（商品 ¥29.70 + 配送费 ¥0.00）
分摊方式：商品优惠按原价比例分摊 · 配送费按人头均摊

成员              原价    占比      应付     共省
-------------------------------------------------
小美            ¥14.00   28.6%     ¥8.48    ¥5.52
阿强            ¥16.00   32.7%     ¥9.70    ¥6.30
老王            ¥19.00   38.8%    ¥11.52    ¥7.48
-------------------------------------------------
合计            ¥49.00  100.0%    ¥29.70   ¥19.30

核对：各人应付加总 = ¥29.70，与订单实付一致 ✓
```

更多口径（优惠按人头均摊、配送费由发起人承担等）见 `references/split-algorithm.md`。

## 目标用户

- **办公室小团队 / 项目组**：每周下午茶、加班餐拼单的发起人——不用再自己垫钱算账
- **拼单"发起人"**：最常吃亏的那个人。本技能让账单透明，谁也不用不好意思
- **学生党 / 室友**：一起点外卖，AA 到分
- **公司行政 / 团餐负责人**：团餐场景下按部门/个人拆分费用
- **重度麦门信徒**：想用券用满，又不想为分账吵架

## 技术要点

- **纯标准库**：分账脚本只依赖 Python 3.9+ 标准库，无第三方依赖，`python -m unittest` 即可跑测试。
- **金额全程用「分」**：内部一律整数运算，规避浮点误差；仅在输入输出处用 `Decimal` 精确换算。
- **可复现**：余数并列时按成员原始顺序分配，同输入必得同输出。
- **价格单位处理**：麦当劳 MCP 中**只有 `calculate-price` 返回「分」**，其余返回「元」，
  技能内已固化该规则，详见 `references/tools.md`。
